## Summary

Full UI audit + bug-fix + Castro-parity feature pass for the Fidel Android diagnostics app
(Flutter 3.44 stable via `fvm`, Riverpod, go_router, Kotlin native bridge).

### Bugs fixed (native + Dart)
- **CPU**: per-core usage was always 0% — `/proc/stat` delta window now seeds previous
  totals per core and reports `coreUsages` + `coreFreqsMhz` per core.
- **Thermal**: only battery was shown — now emits `zones: [{name, rawType, tempC}]` and the
  UI lists every thermal zone with a severity chip.
- **Battery**: voltage stuck at 0 and current missing — now reads `voltageV`,
  `currentMicroAmps`/`averageCurrentMicroAmps`, `chargeCounterUah`, `energyCounterNwh`,
  and derives an estimated instantaneous current via coulomb counting (negative = discharging).
- **Cameras**: reported 2 logical cameras only — now enumerates logical + physical sensors
  with focal lengths, apertures, physical sensor size, pixel count and orientation.
- **Network**: never loaded — emits `kind:"error"` frames on failure and a seed frame so the
  UI is never stuck on a spinner; BLE scan toggle reports `{ok, reason}`.
- **Bluetooth environment**: scan start/stop wired through `SystemChannels` with error frames.

### Features added (Castro parity)
- **Multi-touch screen tester**: real pointer tracking (not just color flips), touch-path
  overlay, back-button support.
- **Vibration tester**: pattern presets via `testVibration({patternMs, amplitudes})`.
- **Flashlight / torch tester**: `setTorch({enabled})` toggle.
- **Network speed test**: ping + download + upload phases (pure `dart:io`, cancel-safe).
- Expressive glass design system (`theme_tokens`, `app_typography`, `app_themes`,
  `lib/core/ui/*` components) and rebuilt dashboard / sections / testers / settings.
- Sensors show friendly names (with `ID: <hardware>` + vendor secondary) and capability
  values formatted to 3–4 significant figures via `measurement_formatter`.

### Localization
- 91 new keys added across `en_us`, `de_de`, `es_es`, `fr_fr`, `ar` (418 keys each, parity clean).

## Build / toolchain fixes (required to compile in this environment)
- `android/build.gradle.kts`: forced AGP `8.11.1` on every subproject's buildscript so
  `flutter_native_splash`'s hardcoded `8.7.0` no longer breaks resolution.
- `android/build.gradle.kts`: `resolutionStrategy.force(...)` for the AndroidX Test 1.6.2
  suite (`androidx.test:runner:1.6.2`, `:rules:1.6.0`, `:monitor:1.6.0`,
  `espresso-core:3.6.1`) because Google Maven no longer serves the `1.2+` metadata listings.
- `CpuEventsStreamHandler.kt`: `lastCoreTotals` retyped from `Map<Int, Pair<Long,Long>>` to
  `Map<Int, CpuStat>`; usage now reads `prev.total`/`prev.idle`.
- `pubspec.yaml`: removed the `android_12:` splash block so Android 12+ uses the legacy
  full-screen splash drawable instead of the adaptive-icon mask (which cropped the logo).
- `android/gradle/wrapper/gradle-wrapper.properties`: pinned `gradle-8.14-bin` (the `-all`
  distribution is not required and fails to fetch in constrained networks).
